# 📚 StudyMate – AI Student Study Assistant

StudyMate is an AI-powered student utility application designed to help college students understand and revise their study material more effectively.

The application uses the Google Gemini API to provide four useful study features:

- 📝 Summarize Notes
- ❓ Generate Quiz
- 💡 Explain Concepts
- ✍️ Improve Answers

---

## 🎯 Problem Statement

Students often spend a lot of time converting long study notes into summaries, preparing questions for revision, understanding difficult concepts, and improving written answers.

StudyMate provides these utilities in one simple interface using Generative AI.

---

## ✨ Features

### 1. 📝 Summarize Notes

Students can paste their notes and receive a concise summary containing the important concepts.

### 2. ❓ Generate Quiz

The application generates a 5-question quiz from the student's notes.

The quiz contains a mixture of:

- Multiple-choice questions
- Short-answer questions
- Correct answers

### 3. 💡 Explain Concepts

Students can enter a topic or question and receive a simple step-by-step explanation with examples when useful.

### 4. ✍️ Improve Answer

Students can enter an answer and receive:

- Grammar corrections
- Improved sentence structure
- Clearer writing
- A brief list of improvements
